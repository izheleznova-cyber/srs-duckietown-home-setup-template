## Требования к истории работы
Работа должна содержать не менее четырёх содержательных коммитов:
1. docs: добавлена информация о компьютере
2. setup: установлен и проверен WSL
3. setup: установлен и проверен Docker
4. result: добавлен результат запуска Duckiematrix

Коммиты update, исправлено, 123 содержательными не считаются.
Удалять историю коммитов и использовать force push запрещается.

Этап 5. Создать папку для скриншотов
GitHub не создаёт пустые папки, поэтому добавим в неё служебный файл.
1. На вкладке Code нажмите Add file.
2. Выберите Create new file.
3. В поле имени файла напишите:

5. Нажмите Commit changes.
Этап 6. Создать GitHub Classroom
1. Откройте classroom.github.com.
2. Нажмите Sign in with GitHub.
3. Разрешите GitHub Classroom доступ к аккаунту.
4. Нажмите New classroom.
5. Выберите учебную организацию GitHub или создайте новую.
6. Назовите класс, например:
