## Требования к истории работы

Работа должна содержать не менее четырёх содержательных коммитов:

1. `docs: добавлена информация о компьютере`
2. `setup: установлен и проверен WSL`
3. `setup: установлен и проверен Docker`
4. `result: добавлен результат запуска Duckiematrix`

Если возникла и была исправлена ошибка, используйте отдельный коммит, например:

```text
fix: исправлена интеграция Docker с WSL
```

Коммиты `update`, `исправлено`, `123` содержательными не считаются.

Удалять историю коммитов и использовать `force push` запрещается.

## Правила безопасности

- Не размещайте в репозитории пароли, токены и ключи доступа.
- Перед загрузкой скриншота проверьте, нет ли на нём конфиденциальных данных.
- Не изменяйте названия папки `evidence` и предусмотренных файлов.
- Все исправления выполняйте в этом же репозитории. Новую ссылку отправлять не нужно.
